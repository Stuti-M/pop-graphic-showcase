# Stuti Mohapatra Portfolio

## Goal
Build a one-page, highly interactive developer portfolio with maximalist pop-graphic composition and a strict copper, rust, and aqua visual identity.

## Page structure
- Create a full-viewport hero with oversized overlapping name typography, scrolling background text, custom cursor, and an original circuitry-inspired avatar graphic.
- Add an asymmetrical comic-style About section featuring the supplied biography and internship experience.
- Build two large project panels with technology tags, harsh shadows, pointer-responsive tilt, and aqua pattern reveals.
- Present skills as layered, continuously scrolling tickers that stay readable and pause for reduced-motion users.
- Finish with an oversized contact area containing Bhubaneswar location and clear GitHub, LinkedIn, Discord, and email actions.

## Interaction and polish
- Add subtle glitch treatments, hover displacement, card tilt, marquee motion, and a custom cursor for fine-pointer devices.
- Preserve keyboard focus states, semantic landmarks, readable contrast, mobile layouts, and reduced-motion fallbacks.
- Add unique portfolio metadata and verify the finished page at desktop and mobile sizes.

## Technical details
- Define all palette, typography, shadows, pattern, and animation values as semantic tokens in the global design system.
- Build focused React components for the cursor, artwork, project panels, and skill tickers within the home page.
- Use inline SVG only for the bespoke circuitry/avatar artwork; no external images or backend are required.
- Contact links without supplied destinations will use safe placeholders or direct identity links where possible, without inventing personal data.
