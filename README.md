# Pop-Art Portfolio

Build a highly interactive, tech-savvy developer portfolio website with a maximalist, pop-graphic art style.

Visual Identity & Styling:

Color Palette: Strictly use #8C5738 (Copper Brown), #73362A (Deep Rust), and #8FCCC9 (Light Aqua/Teal, acting as the Pantone 14-4812 TCX pop color). You may add complementary colours if you feel like it would go with the theme

Aesthetics: Maximalist and abstract pop-graphic. I want overlapping geometric shapes, halftone dot patterns, bold and oversized typography, and heavy contrast. Ensure it feels unique, cool, and highly energetic. Use custom cursors and glitch or tilt hover effects on interactive elements.

Page Structure & Content:

1. Hero Section:

Headline: "Stuti Mohapatra" in massive, bold, overlapping typography.

Subheadline: "First-year Computer Science Engineering student & Competitive Builder".

Visuals: A continuous scrolling marquee text in the background with an abstract, pop-art style tech avatar or circuitry graphic.

2. About Me Section:

Text: Highlight hands-on experience across web development, embedded/IoT systems, and multi-agent AI. Mention being a 2x hackathon runner-up actively seeking Software Engineering internships. Include experience as a Software Developer Intern at Paradip Port Authority.

Design: Present this as an asymmetrical, stylized comic-book-style text bubble or a bold card with a harsh drop shadow.

3. Projects (Use bold, pop-art style cards that tilt and reveal abstract teal patterns on hover):

Project 1: "Smart Safety Watch: AI-Powered Offline Emergency Wearable". Include tech tags: Java, Spring Boot, Edge Impulse (TinyML), LoRa Mesh, MQTT. Describe it as featuring autonomous edge intelligence and decentralized offline communication.

Project 2: "Sentinel-X: Multi-Agent AI System". Include tech tags: n8n workflow automation, Groq LLMs. Mention it secured 2nd Place at the Anant Chakra Agentic AI Hackathon.

4. Skills Section:

Design: A chaotic but readable grid or multiple overlapping marquee scrolling tickers.

Skills to Include: Python, Java, JavaScript, Embedded C++, Spring Boot, n8n, Groq LLMs, Tailwind CSS, Edge Impulse, Data Structures & Algorithms.

5. Footer/Contact:

Design: A massive footer with abstract teal and rust shapes.

Details: Location: Bhubaneswar, Odisha, India. Provide bold, stylized buttons for GitHub (Stuti-M), LinkedIn, Discord (stuti_k_73), and Email[cite: 1].
